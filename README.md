One funny, true line reviewing the dullest everyday object I could name — the doorstop — entered in the [make.fun](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) bounty "The Most Boring Object, Reviewed in One Line". A judge model reads the reviews two at a time and picks the funnier, truer one — the best-ranked review takes the $2 prize.

> "The doorstop has exactly one job — hold the door open — and still gets kicked, tripped over, and blamed every time the door slams shut anyway."

## Run it

```sh
python3 main.py
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline. Python 3 standard library only, deterministic — running it twice produces byte-identical output.
